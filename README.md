# 墨韵书法篆刻艺术平台

一个专注于书法艺术和篆刻艺术的在线展示与分享平台。

## 🎨 平台特色

### 📜 书法艺术
- **五大字体展示**：楷书、行书、草书、隶书、篆书
- **高清作品图片**：使用Unsplash高质量书法相关图片
- **智能分类筛选**：按字体类型、作者、热度筛选
- **互动交流**：点赞、评论、收藏功能

### 🔴 篆刻艺术
- **专业篆刻展示**：汉印、秦印、古玺、明清流派、现代创新
- **材质分类**：寿山石、青田石、昌化石、巴林石等
- **印章详情**：印文内容、篆刻风格、材质规格
- **篆刻文化**：历史、技法、文化内涵

### 🌟 用户体验
- **水墨风格UI**：传统与现代结合的优雅界面
- **响应式设计**：完美适配桌面端和移动端
- **流畅交互**：悬停动画、过渡效果
- **社区功能**：用户关注、作品分享

## 🚀 技术栈

### 前端
- **Vue 3** - 渐进式JavaScript框架
- **Vue Router** - 单页面应用路由管理
- **Pinia** - 状态管理库
- **Element Plus** - Vue 3组件库
- **Vite** - 下一代前端构建工具

### 设计特色
- **水墨风配色**：传统书法色彩搭配
- **渐变背景**：优雅的视觉层次
- **卡片布局**：现代化的内容展示
- **交互动画**：流畅的用户体验

## 📱 主要功能

### 1. 首页展示
- 书法五体分类导航
- 热门书法作品展示
- 精选篆刻作品推荐
- 篆刻艺术学习资源

### 2. 作品浏览
- 书法作品网格展示
- 篆刻作品专业展示
- 作品详情页面
- 相关作品推荐

### 3. 用户系统
- 用户注册/登录
- 个人资料管理
- 作品集展示
- 社区互动功能

### 4. 搜索功能
- 多维度搜索
- 分类筛选
- 热门关键词
- 智能推荐

1. **文化传承**：专注传统书法和篆刻艺术

## 📦 本地开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build
```

## 🚀 部署说明

项目已配置GitHub Actions自动部署，推送到main分支即可自动部署到GitHub Pages。

### 手动部署
1. 构建项目：`pnpm build`
2. 上传 `dist` 目录到GitHub Pages
3. 配置仓库的Pages设置
